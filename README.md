# Robotics Foundations

A documented progression from foundational robotics concepts toward biomedical
and assistive robotics projects.

## Goal

Develop a practical understanding of sensors, actuators, electronics, control
systems, kinematics, and embedded systems, then apply that knowledge in
progressively more capable projects.

## Background

I am studying medical and molecular biochemistry alongside computer science.
This repository connects that background with my interests in biomedical
robotics, biosensing, assistive technology, and human-machine systems.
